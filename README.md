American Renewal Party (ARP) - Campaign Website

Sitio web oficial de la campaña política para Evelyn Carter y David Hayes (American Renewal Party).

Descripción

Este es un sitio web estático simple de una sola página (Landing Page) creado con HTML y CSS puro. Está diseñado para ser completamente responsivo e incluye textos bilingües (Inglés/Español) para llegar a una audiencia más amplia.

Estructura del Proyecto

index.html: El documento principal de la página web.

css/styles.css: Hoja de estilos principal que controla la apariencia de la página.

assets/images/: Carpeta destinada a almacenar las imágenes estáticas del proyecto (fotos de los candidatos, etc.).

Cómo probar localmente

Clona este repositorio o descarga el código fuente.

Asegúrate de colocar las fotos de los candidatos (evelyn.png y david.jpg) dentro de la carpeta assets/images/.

Abre el archivo index.html en cualquier navegador web moderno. No se requiere servidor local para visualizarlo.
